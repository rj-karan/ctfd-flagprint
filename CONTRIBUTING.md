# Contributing

Thanks for helping make flag sharing a solved problem.

## Bugs and ideas

Open an [issue](https://github.com/rj-karan/ctfd-flagprint/issues). For bugs, say which CTFd version, which delivery
mode (flag, replace, script, variants) and whether you run in Docker. A failing test or a copy of the admin error
message helps most.

## Pull requests

1. Fork, branch, change.
2. Run the tests (see [Development](README.md#development)). Add one for anything you fix or add.
3. Keep the player side quiet: nothing a player can see should mention Flagprint or hint that flags differ per team.
4. Keep it small. One change per pull request is easier to review and ship.

Code style: plain Python and vanilla JavaScript, comments only where the code can't say it. No new dependencies
without a reason in the PR.

## Security issues

Please don't open a public issue. See [SECURITY.md](SECURITY.md).
