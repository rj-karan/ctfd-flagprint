# Code of conduct

Be kind, be direct, assume good faith. Disagree about code, not people.

Harassment, personal attacks, and publishing others' private information are not welcome here, in issues, pull
requests or discussions. Maintainers may edit, hide or remove contributions that cross that line, and block repeat
offenders.

To report a problem, use GitHub's report feature on the comment, or open a private security advisory if it's sensitive.
